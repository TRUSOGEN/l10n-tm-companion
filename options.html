L10n TM Companion Settings

Starling TM

AK/SK are tied to your personal account. Configure them once here; the popup will then load the projects your account can access. Apply for AK/SK on Starling →

Full credentials are stored in both Chrome local storage and the official Starling CLI config. Chrome storage is plaintext to provide a recovery copy if the Native Host config is cleared; use this only in your managed browser profile.

Advanced: Native Host and TM query mode

Leave CLI path empty to auto-detect starling-cli. Vendor, projects, and target locale are selected in the popup for each run.

Batch mode uses the PPE API verified in this project. It preserves all input order and sends three source texts per request until Starling confirms a larger sourceContents limit.

LLM API (optional)

AI rewrite is off by default — TM queries work fine without it. To enable, fill in your own LLM credentials (company LLMBox or other compatible API).

When off: TM hit uses TM, missed entries are left empty marked "AI disabled". When on, pick a provider below and fill in API Key.

Personal wak_… Access Key is for local Demo use. Production distribution requires a tenant-signing backend; never put a tenant API Secret in the extension.

Feishu Spreadsheet

Requires a Feishu custom app with sheets:spreadsheet permission. Create / manage app on Feishu Open Platform →

Open the Side Panel from a Feishu Spreadsheet to select it automatically. Spreadsheet, Sheet, source column, data start row, and output start column are configured in the Working spreadsheet section.

Dynamic column layout

The Side Panel detects standard source headers in the first 20 rows and lets you confirm or change the source column, data start row, and output start column for each Sheet.

The output occupies six consecutive columns: Best TM Match, Orig Match %, Rewritten Segment, New Match %, Reached 85%?, and CD review valid?.

This target stores ROI run history only. Spreadsheet write-back remains separate.

App ID and App Secret are stored in this Chrome profile. Each user who installs the extension must enter their own approved app credentials.
